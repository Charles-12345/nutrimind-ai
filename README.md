# 🥗 NutriMind AI™
*Your Personal AI Nutrition Coach*
*Built with ❤️ by **DOKA CHARLES DANIEL** · Powered by Streamlit and Hugging Face Transformers*

[![Streamlit](https://img.shields.io/badge/Streamlit-FF4B4B?logo=streamlit&logoColor=white)](https://streamlit.io)
[![HuggingFace](https://img.shields.io/badge/🤗_HuggingFace-FFD21E)](https://huggingface.co)
[![Python](https://img.shields.io/badge/Python-3.10+-3776AB?logo=python&logoColor=white)](https://python.org)

NutriMind AI is a Streamlit-powered nutrition app that uses **Mistral-7B-Instruct** (via HuggingFace) to analyze meals, generate personalized meal plans, suggest recipes, and track your health progress.

---

## ✨ Features

| Feature | Description |
|---|---|
| 🍽️ **Food Logger** | Describe your meal in plain English — get instant calorie & macro breakdown |
| 📅 **Meal Planner** | AI-generated 1/3/7-day plans tailored to your goal |
| 🍳 **Recipe Finder** | Enter what's in your fridge — get 2 personalized recipes |
| 📈 **Progress Tracker** | Log your weight daily and watch your journey unfold |

## 🧠 LLM Used

**Mistral-7B-Instruct-v0.3** via HuggingFace Inference API
- Free tier available
- No GPU required (API call)
- Great instruction-following for nutrition tasks
